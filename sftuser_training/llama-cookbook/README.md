# Customized llama-cookbook source

This directory contains the training package used by the user-simulator SFT
pipeline, derived from [Meta llama-cookbook](https://github.com/meta-llama/llama-cookbook).
It includes the user-side dataset, end-conversation token handling, and training
customizations. See the [SFT instructions](../README.md) for installation and usage.
The original [MIT license](LICENSE) and source notices are retained.
